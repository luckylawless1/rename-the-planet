## What it does

`main.py` writes one line to `/output/entry.txt`: a funny new name for a planet
in our solar system, with the why in the same breath — under 200 characters.

> Venus is now "The Toxic Ex" — stunning from afar, hides behind thick clouds, runs at 465°C, and spins backwards purely out of spite.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
